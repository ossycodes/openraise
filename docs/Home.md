# OpenRaise

Open-source, self-hostable crowdfunding for African communities. Verified
creators, local and international donations, fast payouts, and AI help writing
the story. Anyone can run it: an NGO, a church, a diaspora association, or a
startup.

> [!tip] Using this vault
> Open the `docs/` folder as a vault in Obsidian. Track work by editing a
> feature note's `status` property (`idea` → `planned` → `in-progress` →
> `shipped`); [[Tracker.base|the tracker]] updates itself, grouped by milestone.
> Record any choice that would surprise a newcomer in [[Decisions]].
